# AGENTS.md

## Project context

SplurgeGuard is a 100% offline, gamified personal finance PWA. There is **no backend, no database, no external APIs**. All persistent state lives in the browser's `localStorage`. The only service needed for local development is the Vite dev server.

For full architectural context, data model, algorithms, copy rules, and a contribution cheat sheet, see [`SplurgeGuard_AI_Context.md`](./SplurgeGuard_AI_Context.md). That document is slightly outdated in spots but remains the authoritative deep reference for AI assistants working on this codebase.

A packed single-file XML snapshot of the source tree (generated by [Repomix](https://repomix.com)) is committed at [`repomix.xml`](./repomix.xml). Use it for fast LLM context loads. Regenerate with:

## Cursor Cloud specific instructions

### Overview

The only service needed for local development is the Vite dev server — no DB, no auxiliary services to spin up, no secrets required. The app shows a setup wizard on first load (when `localStorage` is empty). After completing setup, the Dashboard appears.

### Running the dev server

```bash
bun run dev
```

Starts Vite on `http://localhost:8080/` with HMR. The port `8080` is configured by `@lovable.dev/vite-tanstack-config`. Use a persistent tmux session for long-running dev (see cloud-agent tmux conventions).

Onboarding is two phases: profile form → savings slider. Finishing setup requires **holding** `COMMIT SAVINGS` (~1.5s) on `HoldSecureButton` (pointer events, not a plain click).

### Lint / Format / Build

- **Lint:** `bun run lint` — ESLint with Prettier integration. The codebase has pre-existing Prettier formatting issues (single quotes vs double quotes); these are not blocking.
- **Format:** `bun run format` — auto-fix formatting with Prettier.
- **Build:** `bun run build` — produces both client and SSR (Cloudflare Workers) bundles in `dist/`.

### Architecture notes

- `vite.config.ts` delegates to `@lovable.dev/vite-tanstack-config`, which already bundles TanStack Start, React, Tailwind CSS v4, tsconfig-paths, and Cloudflare plugins. **Do NOT add duplicate plugins.**
- File-based routing via TanStack Router in `src/routes/`. Generated route tree at `src/routeTree.gen.ts` (do not hand-edit).
- Path alias `@/*` maps to `src/*`.
- The Cloudflare Workers entry (`src/server.ts`) is only relevant for production deployment, not local dev.
- All game state is centralized in `src/context/AppContext.tsx`. Pure game-logic helpers live in `src/lib/` (`ranks.tsx`, `milestones.ts`, `amortization.ts`, `splurge-utils.ts`, `dateUtils.ts`, `contracts.ts`, `archetypes.ts`, `schemas.ts`).
- Feature-level UI lives in `src/components/splurge/`; generic shadcn/Radix primitives live in `src/components/ui/`.
- Currency-aware inputs use the `useCurrencyInput` hook. The Exchange stepper uses `useLongPress` with a latest-callback ref pattern for gear-shifting.

### Critical invariants — do not break these

- **`totalDP` ≠ `ascensionXP`.** They are two separate ledgers. Positive actions credit both; Exchange purchases debit **only** `totalDP`. Breaches penalize both. Never debit `ascensionXP` from the Exchange.
- **Vault unlock toasts are deduplicated** via a `useRef<Set>` so resuming the app doesn't spam notifications. Preserve that pattern.
- **Payload Decay is stateless.** Active decays are *projected* into the Smart Daily Limit on every render — never stored as a mutable array.
- **The Vault cooling tick is a single global 60s `setInterval` + `visibilitychange` listener.** Don't add per-item timers.
- **The setup wizard** must remain the first thing a user with empty `localStorage` sees.

## Cosmetic / copy rules

- The tone is "tactical, gamified, slightly menacing." Keep terminal-style language: `[VAULT]`, `[DIRECT]`, `[REVERT]`, `SECURE`, `YIELD`, `BREACH`, `DEMOTION`.
- Money is rendered with `fmtMoney` from `src/lib/splurge-utils.ts`. Respect the VND ↔ USD toggle.
- Rank avatars are inline SVG in `src/lib/ranks.tsx`. No external images.
